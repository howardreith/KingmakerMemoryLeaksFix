## Resolved or reframed

* **"A ConsoleUI namespace means console-only."** Not true for this build: the desktop `TurnBasedModeUIController` (PC namespace)
  creates the `_ConsoleUI` `InitiativeTrackerVM`/`InitiativeTrackerUnitVM`, bound to `*PCView` views. Console UI proper is selected by
  `Game.ControllerMode` at startup (gamepad), so both paths can run on Windows.
* **MVVM lifecycle logging as a passive counter** (`UILog.VMCreated/VMDisposed`): not emitted in this release build (0 lines in two
  full session logs that created view models). Unavailable.
